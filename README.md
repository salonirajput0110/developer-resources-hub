# Developer Resource Hub

A simple and responsive learning platform where users can explore useful developer resources and add their own resources.

## Features

- Resource cards for Web Development, App Development, AI/ML and Tools
- Search resources by title or description
- Filter resources by category
- Add new learning resources
- User-added resources are saved using Local Storage
- Upvote resources
- Delete user-added resources
- Default resources cannot be deleted
- Dark and Light mode
- Responsive design for mobile and desktop

## Tech Stack

- HTML
- CSS
- JavaScript
- Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

No backend or installation is required.
